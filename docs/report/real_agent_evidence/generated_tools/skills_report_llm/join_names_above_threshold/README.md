# join_names_above_threshold

Parse a CSV string, filter rows where the score strictly exceeds a threshold,

## Parameters
- csv_text (string) [required]
- threshold (number) [required]
- name_field (string)
- score_field (string)
- separator (string)

## Imports
csv, io, typing

## Usage
Use `example_input.json` as a starting point for invocation.
