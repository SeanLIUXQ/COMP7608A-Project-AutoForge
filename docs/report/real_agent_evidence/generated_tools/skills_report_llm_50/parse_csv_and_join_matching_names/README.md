# parse_csv_and_join_matching_names

Parse a CSV string and return names from rows whose score exceeds a threshold.

## Parameters
- csv_text (string) [required]
- name_col (string) [required]
- score_col (string) [required]
- threshold (integer) [required]
- separator (string)

## Imports
csv, io, typing

## Usage
Use `example_input.json` as a starting point for invocation.
