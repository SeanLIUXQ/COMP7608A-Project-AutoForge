# join_names_above_score_threshold

Extract names from a CSV string where the score exceeds a threshold.

## Parameters
- csv_text (string) [required]
- threshold (number) [required]
- name_field (string)
- score_field (string)
- delimiter (string)

## Imports
csv, io, typing

## Usage
Use `example_input.json` as a starting point for invocation.
