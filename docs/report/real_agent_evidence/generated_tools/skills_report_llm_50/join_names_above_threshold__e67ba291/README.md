# join_names_above_threshold

Parse a CSV string and return a string containing the names (from `name_column`)

## Parameters
- csv_text (string) [required]
- threshold (integer) [required]
- name_column (string)
- score_column (string)
- separator (string)

## Imports
csv, io, typing

## Usage
Use `example_input.json` as a starting point for invocation.
