# collect_names_meeting_score_threshold

Collect the values of `name_field` from rows where `score_field` is at least `threshold`.

## Parameters
- rows (array) [required]
- threshold (integer) [required]
- score_field (string)
- name_field (string)

## Imports
typing

## Usage
Use `example_input.json` as a starting point for invocation.
