# filter_csv_names_by_score

Return a delimited string of names from rows where the score exceeds the threshold.

## Parameters
- csv_text (string) [required]
- threshold (number) [required]
- name_column (string)
- score_column (string)
- delimiter (string)

## Imports
csv, typing

## Usage
Use `example_input.json` as a starting point for invocation.
