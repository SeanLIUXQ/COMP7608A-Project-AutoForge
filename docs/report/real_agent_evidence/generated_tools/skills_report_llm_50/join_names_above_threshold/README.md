# join_names_above_threshold

Parse CSV and return a comma-separated string of names where score > threshold.

## Parameters
- csv_text (string) [required]
- threshold (integer) [required]
- name_field (string)
- score_field (string)
- delimiter (string)
- quotechar (string)

## Imports
csv, io, typing

## Usage
Use `example_input.json` as a starting point for invocation.
