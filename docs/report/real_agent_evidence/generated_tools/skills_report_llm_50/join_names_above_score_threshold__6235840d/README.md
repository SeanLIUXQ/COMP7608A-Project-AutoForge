# join_names_above_score_threshold

Parse a CSV string, filter rows where a score column exceeds a threshold,

## Parameters
- csv_text (string) [required]
- threshold (number) [required]
- name_col (string)
- score_col (string)
- separator (string)

## Imports
csv, io, typing

## Usage
Use `example_input.json` as a starting point for invocation.
