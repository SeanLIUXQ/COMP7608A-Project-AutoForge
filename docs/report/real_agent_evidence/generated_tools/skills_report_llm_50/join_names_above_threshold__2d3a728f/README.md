# join_names_above_threshold

Filter CSV rows by a numeric score threshold and return the joined name values.

## Parameters
- csv_text (string) [required]
- threshold (number) [required]
- name_column (string) [required]
- score_column (string) [required]
- separator (string)

## Imports
csv, io

## Usage
Use `example_input.json` as a starting point for invocation.
