# parse_csv_and_join_names

Parse CSV text, filter rows where a score column is greater than a threshold,

## Parameters
- csv_text (string) [required]
- threshold (number) [required]
- name_col (string)
- score_col (string)
- delimiter (string)

## Imports
csv, io, typing

## Usage
Use `example_input.json` as a starting point for invocation.
